REFERÊNCIA RÁPIDA

Pequeno assembly. Grandes descobertas.

Este simulador usa uma arquitetura didática própria, inspirada na ideia de editor + CPU + memória do Assembler Simulator. Não é um emulador x86, ARM nem compatível com o conjunto de instruções desse site.

Operandos, dados e rótulos

M13 é um endereço; #5 (ou 5) é um imediato; ACC é o acumulador. Declare dados com M13: 7 e rótulos com inicio:. Vírgulas são opcionais e ; inicia comentários. O programa começa em M0.

Convenções do modelo

  • 64 posições compartilhadas entre instruções e dados. Cada instrução ocupa uma posição; portanto, CI avança 1.
  • Inteiros com sinal de 32 bits. DIV trunca em direção a zero; MOD usa o resto com o sinal do dividendo. Overflow e divisão por zero interrompem a simulação.
  • RULA₁ e RULA₂ são entradas. RULA₃ guarda o endereço de destino. ULA mostra a saída e ULA_OP seleciona a operação.
  • O primeiro operando de memória passa por RDM → ACC → RULA₁. Se a segunda origem for ACC, ela é preservada em RULA₂ antes dessa passagem.
  • Z indica resultado zero; N, resultado negativo. LOAD, STORE, MOV, saltos e NOP preservam essas flags. CMP atualiza as flags sem armazenar a subtração.
  • As linhas dos barramentos são trajetos conceituais, não um circuito elétrico real. Cada clique executa uma micro-operação, não necessariamente um pulso de clock de hardware.
  • Voltar restaura registradores, flags e memória. São mantidos os últimos 1.000 passos; a execução automática pausa após 2.000 passos seguidos.

Para usar em aula

Use Modo aula para ampliar o diagrama. Teclas: → próximo passo, ← voltar, Espaço executar/pausar. Clique em um bloco para ver sua função. A montagem reinicia a simulação com o código do editor.

Funciona offline. Nenhum programa é enviado a um servidor. O navegador tenta guardar o último código localmente; use o botão de download para preservá-lo em arquivo.
